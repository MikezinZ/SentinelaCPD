Monitoramento Térmico e de Corrente para CPD

Sistema inteligente ponta a ponta voltado para telemetria em tempo real de infraestruturas de TI críticas. Mede temperatura, umidade relativa e corrente elétrica eficaz (RMS) com transmissão segura via broker MQTT EMQX e persistência relacional automatizada em banco de dados MySQL.

Telemetria Climática
Acompanhamento contínuo de temperatura e umidade com sensor digital DHT22.
Medição Elétrica RMS
Transformador de corrente ZMCT103C com amostragem em 60Hz e isolamento galvânico.
Arquitetura de Borda
Ingestão via Docker (EMQX + MySQL) com controle de acesso e regras em tempo real.

Plataforma IoT e Integração

A plataforma de backend é conteinerizada com Docker Compose, orquestrando um broker MQTT industrial e um banco de dados relacional sem dependência de serviços externos em nuvem.

Broker MQTT (EMQX 5.x)

  • Porta 1883 ativa em rede privada local com autenticação por credenciais.
  • Dashboard administrativo acessível em http://localhost:18083.
  • Motor de regras SQL para extração e mapeamento dos payloads JSON.
  • Conector nativo Data Bridge disparando operações assíncronas no MySQL.

Banco de Dados (MySQL 8.0)

  • Esquema estruturado iot_db com controle de transações.
  • Tabela leituras_dht22 com colunas de temperatura, umidade e corrente.
  • Gestão visual direta via MySQL Workbench na porta 3306.
  • Histórico auditável com registro automático de data e hora no servidor.

Estrutura do Payload Telemetria

{
  "temperatura": 31.0,
  "umidade": 66.8,
  "corrente": 0.12
}

Dispositivos e Circuito de Borda

A camada física foi projetada sobre o microcontrolador ESP32 DevKit v1, assegurando estabilidade elétrica com alimentação compartilhada em barramento e separação de canais de amostragem.

Dispositivo Função Pino ESP32 Tipo de Interface
ESP32 DevKit v1 Processamento, cálculo RMS e conexão Wi-Fi - SoC Xtensa Dual-Core
Sensor DHT22 Monitoramento térmico e umidade ambiente GPIO 27 Digital Single-Bus
Módulo ZMCT103C Leitura de corrente alternada não invasiva GPIO 34 (ADC1) Analógico com Offset DC

Cuidados Técnicos de Montagem

O pino de leitura analógica do ZMCT103C foi estrategicamente alocado no GPIO 34 (ADC1) para impedir qualquer interferência de chaveamento do rádio Wi-Fi integrado da placa. O isolamento galvânico do transformador de corrente garante segurança total contra surtos da rede de 220V em direção à lógica digital.
